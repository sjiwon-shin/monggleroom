# 몽글룸

내 픽셀 캐릭터와 내 방, 그리고 방명록이 있는 작은 개인 홈.
친구에게 주소를 보내면 친구가 캐릭터를 만들어 내 방에 놀러 와 글을 남깁니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 내 홈 만들기 (이름, 한 줄 소개, 캐릭터, 방 분위기) |
| `home.html?u=아이디` | 홈 화면 (노트 모양): 프로필, 방, 다이어리, 사진첩, 방명록, 단짝 |
| `home.js` | 홈 화면 동작 |
| `config.js` | 서비스 이름, Supabase 주소와 키 |
| `store.js` | 저장 (Supabase 또는 이 기기) |
| `maker.js` | 캐릭터 만들기 화면 |
| `room.js` | 방 그리기와 걷기 |
| `avatar.js`, `parts.js` | 캐릭터 부품과 조합 |
| `supabase/sql/01_tables.sql` | 데이터베이스 설정 (1단계) |
| `supabase/sql/02_upgrade.sql` | 방문자 수, 기분, 다이어리, 사진첩, 비밀글, 단짝, 몽글 산책 (2단계) |

## 바로 써보기

`index.html` 을 더블클릭하면 체험 모드로 열립니다. 이 기기에만 저장되고 다른 사람은 볼 수 없습니다.

## 다른 사람도 들어오게 하기

1. https://supabase.com 에서 새 프로젝트를 만듭니다. 방명록 프로젝트와 다른 프로젝트로 만드세요.
2. SQL Editor 에 `supabase/sql/01_tables.sql`, 이어서 `02_upgrade.sql` 내용을 붙여넣고 Run.
3. Project Settings → API 에서 Project URL 과 publishable(anon) key 를 복사해 `config.js` 에 넣습니다.
4. 폴더 전체를 Netlify 등에 올립니다. `tools` 같은 폴더는 없습니다. 전부 올리면 됩니다.

## 구조 메모

- 홈을 만들면 8자 아이디와 24자 열쇠가 생깁니다. 열쇠는 만든 기기의 브라우저에만 저장되고, 그 열쇠가 있어야 홈을 고치거나 방명록을 지울 수 있습니다. 로그인은 아직 없습니다.
- 다른 기기에서 관리하려면 꾸미기 → "다른 기기에서도 관리하기"의 관리 코드를 첫 화면 "관리 코드로 불러오기"에 넣습니다. 코드를 잃어버리고 브라우저 데이터도 지우면 홈을 고칠 수 없습니다.
- 방 안에는 주인과 최근 손님 10명이 걸어다닙니다.
- 캐릭터 코드 형식은 `2:헤어.얼굴.옷.머리색.피부색.옷색.안경.모자` 입니다.

## 출처

이 폴더의 코드(방, 걷기, 저장, 화면)는 새로 작성했습니다.
캐릭터 부품 그림은 AI(GPT Image)로 직접 생성해 추출한 것입니다. 다른 사람의 코드나 그림은 들어 있지 않습니다.
서비스 이름과 용어는 기존 서비스의 상표와 겹치지 않게 지었습니다.
